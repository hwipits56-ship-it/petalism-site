# Philosophy 배경 이미지

페탈리즘 2페이지 — 풀 너비 배경 + 좌하단 흰 글씨 overlay (Kinfolk Home Tour 결).

## 파일

- `bg.jpg` — 메인 배경 이미지 (manifest.json 참조)
- 가로 비율, 풀 너비 풀 화면 사용
- 해상도: 가로 2400px+ (retina + 풀 너비)
- 좌하단에 흰 글씨 올라가니 그 영역 어두운 톤 권장

## 추천 결

깊은 남색 바다 파도 풍경 (사용자 5월 팔레트와 일치).
