# Works 슬라이드 배경 이미지

페이지 3 (Works carousel)에서 누비 / 시간 각 슬라이드 배경으로 사용.

## 파일 위치

- `images/works/nubi/bg.png` (또는 `.jpg`, `.jpeg`, `.webp`)
- `images/works/time/bg.png`

## 결

- Philosophy의 ocean 이미지처럼 풀 너비 시각 임팩트
- 텍스트(우하단 프로젝트 정보)와 카드 row가 위에 올라가므로 배경이 어두운 톤이거나 가독성 보장
- 자동으로 `brightness(0.78)` 필터 적용됨
- 좌하단에 어두운 gradient (텍스트 가독성)

## 추천 결

- **누비**: 따뜻한 봄 풍경, watercolor 결, 텍스타일·종이 결의 추상
- **시간**: 시간의 흐름, 빛·그림자, 한 장면의 정지

## 이미지 없을 때

`#2a2f38` (어두운 회색) fallback. 페이지는 동작하지만 시각 임팩트 약함.
